## 📖 About This Project

This project is a modern, single-page portfolio website designed mainly focusing on a clean structure and a distinct UI aesthetic (using a 0px border radius design philosophy). It includes features like:

- **Dark Mode Toggle:** A built-in theme switcher to transition between light and dark visual aesthetics.
- **Responsive Layout:** Works smoothly on desktops, tablets, and phones.
- **Dynamic Elements:** Features a typewriter effect on the home screen and interactive progress bars for skills.
- **Modern UI:** Built from scratch utilizing modern web design concepts and CSS properties.

## 🛠️ Technology Stack

- **HTML5:** Semantic structure and content organization.
- **Vanilla CSS (index.css):** Styling, layout (Flexbox/Grid), variables for theming, and responsive media queries.
- **Vanilla JavaScript (script.js):** Functionality for the typewriter effect, theme switching, smooth scrolling, and other interactive elements.

## 📁 Sections Included

1. **Home:** Quick introduction with a dynamic typewriter effect and social links.
2. **About Me:** My journey into programming, my philosophy, and my current focus (DSA, AI/ML, and Web Dev).
3. **Skills:** Visual representation of my proficiency in various domains:
   - Frontend & Backend Development
   - Languages: JavaScript, Python, C, C++
   - FrameWorks & DB: Flask, SQL
4. **Featured Projects:** A showcase of recent works with descriptions and code links (e.g., Starbucks Landing Page, Integration Calculator).
5. **Contact:** Readily available information and a feedback/contact form to get in touch.

## 💻 Running the Project Locally

To run this project on your local machine:

1. Clone this repository:
   ```bash
   git clone https://github.com/makwana-akshat/portfolio-website.git
   ```
2. Navigate to the project directory:
   ```bash
   cd portfolio-website
   ```
3. Open `index.html` in your web browser, or use an extension like **Live Server** in VS Code for a better development experience.
